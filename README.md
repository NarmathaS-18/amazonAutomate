Amazon Test Automation using Selenium

## Selenium/Java/TestNG/Maven

This project is a Selenium WebDriver automation script written in Java that automates the following workflow on Amazon.com:

-Launches Google Chrome
-Navigates to Amazon homepage
-Searches for a product (default: shirt)
-Clicks the first search result
-Verifies that the product page is loaded by checking the Add to Cart button
-Takes a screenshot of the product page
-Closes the browser

## Features

- Project uses Maven build tool
- TestNG for Execution and Reporting 
- Modular and Reusable Code Structure
- Explicit waits for stable execution
- Safe Browser Termination 
- Automatic Screenshot Capture
- Console Logging
